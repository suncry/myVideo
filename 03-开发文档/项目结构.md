# 项目结构与修改入口

| 文件 | 责任与常见修改 |
| --- | --- |
| `windows_entry.py` | Windows 运行版入口与意外启动日志 |
| `desktop.py` | 主窗口、影片卡片、详情、设置、扫描与模式切换 |
| `app.py` | SQLite 结构、扫描、文件属性、影片资料与底层操作 |
| `privacy.py` | 分区、验证入口、移动记录、模式备份检查 |
| `windows_auth.py` | HWND 绑定的 Windows Hello 与当前用户凭据回退 |
| `process_utils.py` | 重启 / 恢复时非破坏性地等待旧进程 |
| `background_tasks.py` | 工作线程与主线程结果回调 |
| `scrolling.py` | 滚动路由、浮动滚动条和安全筛选控件 |
| `actor_search.py` | `<name>` 搜索模板、编码校验及共用设置保存 |
| `insights_ui.py` | 演员浏览、收藏、详情、作品、图集与推荐 |
| `discovery.py` | 演员资料保存、收藏、标签、资料来源及回退 |
| `public_sources.py` / `extra_sources.py` | 公开影视 / 配音人物与作品查询、别名与身份核对 |
| `actor_media.py` / `media_ui.py` | 图集、作品图片取得、图片去重及大图查看 |
| `player.py` | 平台播放器入口；Windows 使用系统默认播放器 |
| `maintenance.py` / `maintenance_ui.py` | SQLite 备份、校验、恢复与文件指纹重新关联 |
| `iina_cleanup.py` / `native/*.swift` | Mac 专用实现，Windows 不调用 |
| `assets` | 图标等静态资源 |
| `tests` | 自动化回归与隔离启动检查 |
| `scripts` | 环境准备、测试、启动、图标与打包 |
| `YingKu-Windows.spec` | Windows exe、动态库、资源与版本信息收集 |

普通和隐私库使用相同表结构，各有独立电影、演员、图片缓存与收藏。搜索模板保存于库外的共用设置。变更数据库结构通过 `app.init_db()` 做可重复迁移，保留评分、备注、文件指纹、演员身份和选中头像。

UI 后台工作交给 `TaskRunner`，更新控件须回到主线程；窗口关闭要停止图片队列。修改图片来源时复用身份关联与去重，不在缩略图预览时自动更换头像。

资料来源覆盖各不相同。TVmaze 主要提供电视剧演职员，Bangumi/Jikan 主要提供配音与动画。失败不会扩大为已核实资料；未确认公开代表作时仅展示资料库已有作品，并明确标注。
