本次没有连接你的真实 Windows 电脑。Windows Hello 的指纹、面容、PIN 以及不支持 Hello 时的当前账户凭据提示，必须在实机完成确认；验证单元测试和 Wine 不能证明生物识别硬件体验。Windows 10 的凭据回退、ARM 模拟运行也未经实机验证。

离线 Python 安装器和 19 个依赖包已备齐，并校验与锁文件一致；一键 PowerShell 开发脚本已检查代码，但首次安装流程尚未在全新真实 Windows 上执行。源码内附可手动触发的 Windows CI 模板，尚未上传或执行远端 CI。

## 验证环境限制与处理

Wine 下 Windows Python 用 subprocess 的管道捕获来启动 Python/GUI 子进程，出现 0xC0000409 提前退出；改用同一环境的 Windows 命令行直接启动，源码场景和交付 exe 均成功。保留成功直启记录，未将此兼容层现象当作真实 Windows 已验证。运行版和测试代码没有为兼容环境加入绕过验证的修改。
