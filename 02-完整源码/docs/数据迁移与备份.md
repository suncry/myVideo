# 数据迁移与备份

## 只在另一台电脑运行软件

复制交付包中的整个 `01-运行版` 文件夹，然后双击 `影库.exe`。不要只复制 EXE；同目录的 `_internal` 是必需运行组件。

## 迁移现有影库资料

影库的数据库、演员资料缓存和截图默认位于：

```text
%LOCALAPPDATA%\YingKu
```

迁移步骤：

1. 在旧电脑彻底关闭影库。
2. 运行源码包中的 `scripts\backup_data.ps1`，或手工复制整个 `%LOCALAPPDATA%\YingKu` 文件夹。
3. 把备份复制到新电脑。
4. 在新电脑彻底关闭影库。
5. 运行 `scripts\restore_data.ps1 -BackupPath "备份文件夹路径"`。
6. 启动影库，在“扫描源管理”中检查路径。盘符或目录变化时，移除旧来源并添加新来源。

恢复脚本不会直接覆盖已有数据；若新电脑已有 `%LOCALAPPDATA%\YingKu`，会先生成带时间戳的安全副本。

## 什么会被迁移

- 影片索引和匹配资料。
- 评分、喜欢、观看状态、播放次数和待处理状态。
- 演员姓名、头像、照片候选和资料缓存。
- 已生成的关键截图和图片缓存。
- 扫描源路径以及隐藏属性恢复记录。

## 需要注意

- 数据库保存的是绝对路径。新电脑盘符不同，旧路径不会自动变成新路径。
- 建议让影片硬盘在新电脑继续使用原盘符；否则重新配置扫描源。
- Windows 文件隐藏属性保存在影片文件和目录本身。数据库中的恢复记录只对原路径有效。
- Qt 窗口布局默认保存在当前 Windows 用户设置中，不属于核心数据库；新电脑会使用默认布局并重新记忆。
- TMDb Token 等联网配置可能需要在新电脑重新填写。
