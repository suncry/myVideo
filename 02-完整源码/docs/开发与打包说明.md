# 开发与打包说明

## 环境

- Windows 10/11 64 位。
- 推荐 Python 3.12 64 位。
- 依赖见 `requirements-desktop.txt`。
- GUI 使用 PySide6，成品使用 PyInstaller 目录模式打包。

## 目录结构

- `desktop.py`：桌面界面、交互、布局和本地截图生成。
- `app.py`：数据库、扫描、文件隐藏/恢复、资料匹配和演员资料逻辑。
- `assets/`：桌面客户端资源。
- `tests/`：自动化测试和界面渲染辅助脚本。备份恢复请使用应用内分区感知的界面。
- `static/`：早期网页原型，保留作历史参考，当前桌面客户端不依赖它运行。
- `YingKu-Windows.spec`：正式 PyInstaller 构建配置。
- `docs/产品规则与迭代基线.md`：后续开发必须先阅读的产品约束。
- `scripts/`：开发、测试、构建和数据迁移辅助脚本。备份恢复请使用应用内分区感知的界面。

## 建立开发环境

在源码目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup_dev.ps1
```

## 从源码运行

```powershell
.\scripts\run_source.ps1
```

## 运行测试

```powershell
.\scripts\test.ps1
```

测试会设置 `YINGKU_DISABLE_STARTUP_TASKS=1`，避免自动扫描真实位置。不要让自动化测试使用真实 `%LOCALAPPDATA%\YingKu`。

## 构建 Windows 运行版

```powershell
.\scripts\build_release.ps1
```

构建结果位于 `dist\影库\`。必须把整个目录一起复制到另一台电脑，不能只复制 `影库.exe`，因为 `_internal` 包含 Python、Qt、FFmpeg 和其他运行依赖。

## 数据位置与开发覆盖项

- 隐私数据库：`%LOCALAPPDATA%\YingKu\film_library.db`；普通数据库：`%LOCALAPPDATA%\YingKu-Public\film_library.db`
- 图片缓存和截图：`%LOCALAPPDATA%\YingKu\` 下的相应目录。
- `YINGKU_SETTINGS_PATH`：将 Qt 窗口设置保存到指定 INI，主要用于测试。
- `YINGKU_DISABLE_STARTUP_TASKS=1`：关闭启动扫描和演员后台任务，主要用于测试。

## 发布检查清单

1. 阅读产品规则，确认未破坏扫描、隐藏恢复、删除和缓存边界。
2. 执行 `scripts\test.ps1`，全部测试必须通过。
3. 执行 `scripts\build_release.ps1`。
4. 使用临时 `LOCALAPPDATA` 和 `YINGKU_SETTINGS_PATH` 启动成品至少一次。
5. 交付整个 `dist\影库` 目录、源码、测试、文档和依赖清单。
6. 不要交付 `.venv`、`build`、真实 `data`、真实数据库或用户 Token。

## 版本迭代建议

- 每次发布更新根目录 `VERSION` 和 `CHANGELOG.md`。
- 数据库字段只能通过 `init_db()` 中的兼容迁移增加，不能假设数据库是全新创建的。
- 修改文件属性相关逻辑时，必须同时测试“原本可见”“原本已隐藏”“关闭隐藏”“移除扫描源”和“删除最后一部影片”。
- 修改演员刷新时，必须保留普通补全与右键强制刷新两条不同路径。
- 修改布局时，必须验证横屏、竖屏和两套设置恢复。
